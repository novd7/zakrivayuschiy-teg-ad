# Закрывающий тег

Проектная работа спринта 5 курса «Фронтенд-разработка» Яндекс Практикума.

Восемь карточек об этапах обучения. Адаптивная вёрстка, вариативный шрифт Inter, CSS-фильтры, анимация SVG-сердца и модальное окно на элементе `dialog`.

[Репозиторий проекта](https://github.com/novd7/zakrivayuschiy-teg-ad)

Для локального просмотра запустите в папке проекта `python3 -m http.server 8000` и откройте `http://localhost:8000`.
